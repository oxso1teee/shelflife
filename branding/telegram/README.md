# ShelfLife в Telegram: оформление бота и Mini App

Здесь лежит аватар бота и тексты для @BotFather. Часть настроек бот выставляет сам
при каждом запуске, а часть делается только вручную в @BotFather.

| Файл | Что это |
|---|---|
| `avatar.svg` | исходник аватара: знак ShelfLife (полки и часы) на фирменном синем |
| `avatar-640.png` | 640×640, загружается в @BotFather |

Аватар проверен в кружке на 24–160 px, на светлом и тёмном фоне: знак читается на
всех размерах и не обрезается.

## Что бот делает сам

При каждом запуске (`bot/bot/menu.py`, `menu.publish()`) бот выставляет:

- **список команд** — меню «/» в чате;
- **короткое описание** — показывается в профиле бота и при пересылке ссылки на него;
- **описание** — экран «Что умеет этот бот?» в пустом чате;
- **кнопку меню** — только если задан `SHELFLIFE_MINIAPP_URL`: тогда она открывает
  Mini App. Без адреса бот кнопку не трогает: остаётся то, что выбрано в @BotFather
  (по умолчанию это список команд).

Если менять эти тексты вручную в @BotFather, бот вернёт свои при следующем
запуске. Править их нужно в `bot/bot/menu.py`.

## Что делается вручную в @BotFather

Бот сам этого не меняет, а этот проект не трогает настройки @BotFather.

1. **Аватар.** `/setuserpic` → выбрать бота → отправить `avatar-640.png` как фото
   (не как файл).
2. **Имя.** `/setname` → `ShelfLife`.
3. **Домен для входа через Telegram на сайте.** `/setdomain` → домен из
   `SHELFLIFE_DOMAIN`. Без этого кнопка «Войти через Telegram» на сайте не работает.
4. **Mini App** — см. следующий раздел.

## Mini App

Mini App — это сайт ShelfLife внутри Telegram: главная, записи с поиском и
фильтрами, карточка записи (продлить, напомнить завтра, отменить, вернуть, изменить,
удалить), добавление и редактирование, «Скоро», расходы, настройки напоминаний,
отвязка Telegram. Страница — `web/tma/index.php`.

Telegram открывает Mini App только по **публичному HTTPS-адресу**. Локальный
`http://127.0.0.1:8282` не подойдёт.

1. Сайт должен быть доступен по HTTPS на своём домене: в `.env` задан
   `SHELFLIFE_DOMAIN`, на домен указывает A-запись, запущен Caddy
   (`docker compose --profile proxy up -d`). См. `OPERATIONS.md`.
2. Проверьте, что страница открывается в обычном браузере:
   `https://<домен>/tma/index.php`. Должно появиться «Откройте ShelfLife в Telegram».
3. В `.env` укажите `SHELFLIFE_MINIAPP_URL=https://<домен>/tma/index.php` и
   перезапустите бота: `docker compose up -d bot`.
4. После запуска у бота появятся кнопка меню «ShelfLife», кнопка «📱 Открыть
   приложение» на главной и в помощи, а в карточке записи — «✏️ Изменить в приложении».

Без `SHELFLIFE_MINIAPP_URL` бот работает полностью, просто без кнопок приложения.

Необязательно: `/newapp` в @BotFather создаёт прямую ссылку вида
`t.me/<бот>/<имя>`. Для работы кнопок это не нужно. Если будете её создавать,
укажите тот же адрес и загрузите картинку 640×360.

### Проверка в настоящем Telegram

1. Откройте бота → кнопка меню «ShelfLife». Приложение должно открыться на главной
   с вашим именем.
2. «Записи» → откройте запись → «Изменить» → поменяйте название → «Сохранить»
   (это синяя кнопка Telegram внизу экрана). Новое название должно появиться на сайте.
3. В чате с ботом: /list → та же запись с новым названием.
4. Если Telegram не привязан к аккаунту, приложение покажет «Аккаунт ещё не привязан»
   и инструкцию.

## Тексты

**Имя:** ShelfLife

**Короткое описание** (до 120 символов):

> Подписки, сроки годности и обслуживание — с напоминаниями заранее.

**Описание** (до 512 символов):

> ShelfLife следит за сроками: платежи по подпискам, сроки годности, обслуживание техники.
>
> • сводка и ближайшие даты
> • напоминания с кнопками «Продлено», «Отменено», «Напомнить позже»
> • расходы на подписки в месяц
> • быстрое добавление: /add Spotify 15.11 500rub
>
> Нажмите «Запустить» и привяжите аккаунт сайта ShelfLife.

**Команды** в формате `/setcommands`, если нужно задать их вручную:

```
start - Главная: сводка и ближайшее
add - Добавить запись
list - Мои записи
soon - Ближайшие даты
spend - Расходы на подписки
settings - Настройки и привязка
help - Как пользоваться
cancel - Прервать добавление
```

**Кнопка меню:** «ShelfLife», ведёт на адрес из `SHELFLIFE_MINIAPP_URL`.
